# 현재 상태

로컬 dev 브랜치의 소스 기준점은 `997cf3c`이다.

| 영역 | 확인한 상태 | 근거 |
|---|---|---|
| 패키지 경로 변경 | 소스 폴더 변경이 커밋되었고 ROS 패키지명은 유지된다. | [패키지 선언](../limo_capstone_ros/package.xml) |
| 맵핑과 주행 | RTAB-Map, 자동 탐색, 정적 지도 주행 및 통합 실차용 런치가 있다. | [실행 모드](ARCHITECTURE.md) |
| 빌드·시험 자동화 | 문법 검사, Humble 빌드, 테스트 및 로그 업로드가 정의돼 있다. | [CI 정의](../.github/workflows/ci.yml) |

이 문서 작성 시점에는 해당 커밋의 CI 실행 결과와 실차 주행 결과를 확인하지 않았다. 결과가 확보되면 [검증 기록](VALIDATION.md)에 근거를 연결한다.
