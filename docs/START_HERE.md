# LIMO 작업 시작 안내

이 저장소의 루트는 실제 LIMO의 ROS 2 워크스페이스에서 `src/`에 해당한다. 문서의 패키지 경로는 이 루트를 기준으로 읽는다.

이 저장소는 ROS 2 Humble 기반 LIMO의 센서 구동, 위치 추정, 지도 작성과 Nav2 주행을 다룬다. 환경 설치는 [설치 안내](setup_guide.md), 프로젝트 개요는 [README](../README.md)에서 확인한다.

| 하려는 일 | 먼저 읽을 문서 |
|---|---|
| 런치 선택, 노드 또는 설정 찾기 | [구조](ARCHITECTURE.md) · [코드 색인](CODE_INDEX.md) |
| 구현 범위와 시험 근거 확인 | [현재 상태](CURRENT_STATUS.md) · [검증 기록](VALIDATION.md) |
| 설정 변경 이유 조사 | [결정 기록](DECISIONS.md) · [튜닝 이력](tuning_log.md) |
| 이어서 작업하기 | [인수인계](HANDOFF.md) · [작업트리](WORKTREES.md) |
| AI로 코드 수정하기 | [개발 지침](AGENTS.md) |
